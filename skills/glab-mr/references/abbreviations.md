# Abbreviations

**Standard abbreviations used throughout this skill:**

- **MR** = Merge Request
- **MCP** = Model Context Protocol (GitLab MCP tool)
- **IID** = Internal ID (GitLab MR identifier)
- **QA** = Quality Assurance
- **CI/CD** = Continuous Integration/Continuous Delivery
- **WIP** = Work in Progress
- **PR** = Pull Request (GitHub equivalent)
